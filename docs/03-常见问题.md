# 常见问题

## 建池被 429

App API 对**出口 IP** 有配额（约每窗口 180~200 次详情请求）。表现是 `{"message":"Rate Limit"}`。

- 把 `PIX_API_SLEEP` 从 0.9 调到 2.0，`PIX_RATE_SLEEP` 45~60 秒退避重试（代码已内建）
- 一页 30 条自带收藏数，所以正常建池只需「tag 数 × 2 + 画师页数」量级的请求
- 换成住宅 IP / 换节点能立刻恢复

## 池子里 R18 是 0

- `env` 里没有 `PIX_USE_COOKIE`/`PIX_R18_OK` 时不会跑 R18 检索
- 或者 token 失效：检索会**静默返回空列表**（不是 401），表现就是「326 次搜索全 0 行」
- 判断方法：`pixcli.py status` 看 `r18` 数；再看一次单条详情是否 200

## 出的图质量差 / 太冷门

门槛在 `env` 里，不用重建池子：

```
PIX_MIN_BM_ABS=800        # 非 R18
PIX_MIN_BM_ABS_R18=300    # R18
PIX_TOP_RATIO=0.15        # 只在更好的 15% 里抽
```

## 图被平台吞了

插件已四级兜底：合并转发 → 重编码直发（缩 0.995 + 2px 白边 + 去元数据）→ 传群文件 → 明确报失败。
如果全部失败，说明平台拒的是这张图的**资源本身**，换一张就好。

## 池子太小（比如某个 tag 只有几十张）

- 提高 `PIX_TAG_PAGES`（每页 30 条）
- 给口语词配「邻近 tag」（例如 `肚脐` → `おへそ / へそチラ / へそ出し / 水着`）
- 定向命令只在前 30% 里抽，子集小的时候可以把 `PIX_TOP_RATIO` 临时调大

## `unknown_word`

口语词没命中任何 tag。用 `pixcli.py tags --keyword <词>` 看池子里有哪些；中文名 / 别名 / 日文 tag 都认（`おへそ`、`肚脐`、`露脐` 都能命中）。

## 想加画师 / 加词

改 `db/*.xlsx` 后重跑 `python pixdb.py`，再重建池子即可；`推荐星级` 缺省按 3 星。
